# 变更：自动化 DOC↔TXT 同步

## 为什么要做
在提供的 `copy` 文件夹内，手工在 Word 文档与 `.txt` 之间复制粘贴既耗时又容易出错。需要一个稳定的 Python 流程：把 `.doc/.docx` 内容批量导出为 `.txt`，再把编辑后的 `.txt` 批量生成对应的 `.docx`，并按当天日期分目录保存结果。

## 会改变什么
- 提供一个 Python 命令行入口：输入源文件夹（例如 `copy`），并校验其存在性。
- 按当天日期自动创建两个同级输出目录：`<YYYYMMDD>-txt-<源文件夹名>` 与 `<YYYYMMDD>-doc-<源文件夹名>`（例如 `20260108-txt-copy`、`20260108-doc-copy`）；当目录已存在时应可复用并给出清晰提示。
- 递归遍历源文件夹内所有 `.doc` / `.docx`：提取纯文本内容（UTF-8），在 TXT 输出目录中生成同名 `.txt` 文件，并保留相对路径结构。
- 遍历 TXT 输出目录中的所有 `.txt`：在 DOC 输出目录中生成同名 `.docx` 文件（使用轻量依赖），将 TXT 内容原样写入文档正文。
- 输出转换统计与失败列表，便于人工复核与重跑。

## 影响范围
- 影响的规格：`doc-text-sync`
- 影响的代码：新增 Python 脚本（路径待定）与少量目录/转换辅助工具与验证用例。
